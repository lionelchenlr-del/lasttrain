# 《末班車 LAST TRAIN》Roblox Studio 套件

可直接在 Roblox Studio 開啟的第一人稱恐怖遊戲原型。公開起始地點是車站大廳；初次進入會播放劇情簡介，玩家可選擇 1 到 4 人組隊。隊伍最多等候 10 秒，人數到齊後倒數 3 秒，接著傳送到獨立保留伺服器。每站相隔 600 studs，列車行駛間有更長的探索路段。玩家可在三節連通車廂內自由走動；到站時可穿過月台側車門，或用「下車到月台」提示離車。第六站的選擇會影響最終分支，第七站提供一般、真相與隱藏結局。

## 開始遊玩

1. 開啟 `LastTrain.rbxlx`。
2. 按工具列的 **Play**，初次進入會看到故事簡介。關閉後走進大廳的 **1–4 人配對光圈箱**，站進去便會加入隊伍；箱頂會顯示人數和倒數。也可在大廳選單中操作。面板可用右上角 **×** 收起，再按 **大廳選單** 開回；角色商店也有獨立的 **×** 關閉。Studio 會在本機切換到遊戲場景，不需要 Roblox 傳送服務。
3. 第一位玩家選擇本班人數；其他玩家走進光圈箱加入同一隊伍。入口會顯示隊伍人數。目標人數在 10 秒內到齊時倒數 3 秒出發；時間到則以目前隊伍出發，最多 4 人。
4. 在停靠站靠近月台側車門按 **E** 上車；要下車可直接走出開啟的車門，或使用車內的 **「下車到月台」** 提示。每站月台都有 **「登上列車」** 提示。
5. **WASD** 移動、**F** 開關手電筒、**M** 開啟角色商店。

列車由三節連通車廂組成，會載著車內玩家移動；第二、三車廂各藏有一段可互動的獨立劇情。大廳依「夜航光站」平面圖重整為無霧、明亮的深藍車站：入口到月台維持中央直通視線，故事與角色商店設在入口附近，四個配對入口分布在左右兩側，並提供雙面人數導視。列車展示使用白色車身、深色車窗與藍色腰線。大廳設有四個可走近互動的配對入口，入口隊伍大小由第一位玩家選定，伺服器會核對玩家與入口的距離並限制隊伍最多四人。配對由伺服器管理，使用保留伺服器分隔每一局；Studio 以本機模式測試配對倒數、場景切換和重生。月台外有跌落保護；死亡後會在目前車站重生。站務員會在中段路程出現。各站的任務、列車廣播提示及結局文字皆為繁體中文。

## 七站劇情與任務

1. **新月站 NEW MOON**：登車並查看沒有目的地的車票。
2. **失語站 SILENT**：調查乘客簿與沉默乘客留下的線索。
3. **回聲站 ECHO**：播放真正的錄音，查明第三次循環。
4. **鏡湖站 MIRROR LAKE**：記錄異常倒影並取得實驗報告。
5. **遺忘站 FORGOTTEN**：查看監視器裡三天前的自己。
6. **終寂站 LAST MAINTENANCE**：搜尋事故紀錄，選擇相信列車長或相信證據。
7. **不存在的終點 HOME TERMINAL**：揭開玩家與事故調查的關係，選擇一般、真相或隱藏結局。隱藏結局需先讀取第六站事故紀錄。

## 專案內容

- `LastTrain.rbxlx`：直接在 Studio 開啟的遊戲 place。
- `default.project.json`：Rojo 專案設定。
- `src/ReplicatedStorage/LastTrain/Shared/GameConfig.lua`：站點故事、任務、獎勵、角色與商品設定。
- `src/ServerScriptService/LastTrain/WorldBuilder.server.lua`：程序生成的七站封閉式站區、完整隧道牆面、貼近月台的三節高鐵風格列車、主題地標和互動點。
- `RoundController.server.lua`：伺服器驗證任務、開關車門、移動列車與結局分支。
- `Matchmaking.server.lua`、`LobbyWorldBuilder.server.lua`：大廳四個 1–4 人走入式配對光圈箱、入口距離驗證、10 秒等候、3 秒發車動畫與保留伺服器傳送。
- `StationmasterAI.server.lua`、`PlayerSpawn.server.lua`、`RecoveryGuard.server.lua`：追逐、重生及跌落保護。
- `src/StarterPlayer/StarterPlayerScripts/LastTrainClient.client.lua`：第一人稱操作、任務 HUD、手電筒與商店介面。

若要編輯程式碼，修改 `src` 後使用 Rojo 同步或重新建置 place。未安裝 Rojo 時，也可以直接在 Studio 編輯 place 中的腳本。

## 角色與 Robux 商店

角色商店會顯示外觀和功能：列車長加快移動、號誌技師延長手電筒照射、深夜站務員縮短怪物的感知距離。遊戲幣角色由伺服器扣款與解鎖；Robux 角色以 Game Pass 查驗，Robux 換遊戲幣以 Developer Product 收據核發。請先在 Creator Dashboard 建立商品，將商品 ID 填入 `GameConfig.lua`；目前範例 ID 為 0，因此需完成商品設定後才會啟用實際 Robux 購買。不要把售價填到 ID 欄位。

Studio 測試期間使用暫存玩家資料。要測試 DataStore 儲存，先發布測試體驗，再於 Game Settings > Security 開啟 Studio Access to API Services。付費商品應先在測試體驗完成設定與驗證。

## 美術與裝置

地圖使用 Future 燈光、弧形站台雨棚、圓柱支撐、黃色止滑導盲帶與青藍燈帶。月台補上細石材分縫、站色方向線與立體月台號碼柱；大廳加入石材地坪鑲線、電子發車資訊、七站路線圖與列車展示底盤／轉向架。列車採台灣高鐵風格的銀白流線外型、收尖車頭、深色連續觀景窗與青金雙色腰線；三節車廂以可通行的連接處銜接，車內設有座椅、扶手、目的地顯示與暖色照明。停靠時只開啟月台側車門，踏板補齊登車處。新增隧道端牆、車站牆板、嵌燈與維修門。第二車廂的失蹤廣播與第三車廂的舊車票，會揭露列車循環與玩家身分。場景由原生 Roblox 零件和內建球面網格組成，方便直接在 Studio 調整或替換成自製／授權 MeshPart、貼圖與音效。環境音留有可填入自有音效 ID 的位置。

請在目標裝置上調整 Studio 的 Editor Quality Level，並檢查低階手機上的可見度和效能。所有音效與外部素材請使用自行製作或取得授權的內容。
