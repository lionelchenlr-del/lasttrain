# 《末班車 LAST TRAIN》Roblox Studio 套件

可直接在 Roblox Studio 開啟的第一人稱恐怖遊戲原型。公開起始地點是車站大廳；初次進入會播放劇情簡介，玩家可選擇 1 到 4 人組隊。隊伍最多等候 10 秒，人數到齊後倒數 3 秒，接著傳送到獨立保留伺服器。每站相隔 2,800 studs，單程行駛約 42 秒；月台末端封閉，不能沿隧道走到下一站。透明車窗與可坐座位已加入，靠近座位按提示坐下，跳躍即可起身。玩家可在三節連通車廂內自由走動；到站時可穿過月台側車門，或用「下車到月台」提示離車。第六站的選擇會影響最終分支，第七站提供一般、真相與隱藏結局。

## 開始遊玩

車門閃爍與車頭接合補修：門框、腰線退出滑門軌道；車頭根部改為封閉的過渡曲面並深入車身。詳見 `TRAIN_FIX_DOOR_CAB_2026-10-24.md`。

2026-10-24 更新：兩處車廂接點新增同高結構底板與外側摺棚，修正通道燈與車廂編號。內裝升級為深藍、象牙白、胡桃木及香檳金配色，外觀採明亮銀色金屬與深色駕駛窗。詳見 `TRAIN_UPDATE_2026-10-24.md`。內裝飾面由 `src/ReplicatedStorage/LastTrain/Shared/TrainLuxury.lua` 管理。

1. 開啟 `LastTrain.rbxlx`。
2. 按工具列的 **Play**，初次進入會看到故事簡介。關閉後走進大廳的 **1–4 人配對光圈箱**，站進去便會加入隊伍；箱頂會顯示人數和倒數。也可在大廳選單中操作。面板可用右上角 **×** 收起，再按 **大廳選單** 開回；角色商店也有獨立的 **×** 關閉。Studio 會在本機切換到遊戲場景，不需要 Roblox 傳送服務。
3. 第一位玩家選擇本班人數；其他玩家走進光圈箱加入同一隊伍。入口會顯示隊伍人數。目標人數在 10 秒內到齊時倒數 3 秒出發；時間到則以目前隊伍出發，最多 4 人。
4. 在停靠站靠近月台側車門按 **E** 上車；要下車可直接走出開啟的車門，或使用車內的 **「下車到月台」** 提示。每站月台都有 **「登上列車」** 提示。
5. **WASD** 移動、**F** 開關手電筒、**M** 開啟角色商店。

列車由三節連通車廂組成，會載著車內玩家移動；車廂端面齊平，橡膠摺棚、踏板和頂棚連續銜接。車身側板分開窗帶，玩家能從車內看出窗外；車窗、側板、地板和頂棚有各自的碰撞面，乘客不能穿牆或跳出車頂。內裝更新成圓潤雙排座椅、置物架、扶手、走道地毯、乘客資訊顯示和暖白燈帶。駕駛室有隔板封住，避免玩家走進不透明的車鼻。第二、三車廂各藏有一段可互動的獨立劇情。大廳依「夜航光站」平面圖重整為深藍車站：入口到月台維持中央直通視線，故事與角色商店設在入口附近，四個配對入口分布在左右兩側，並提供雙面人數導視。列車展示與遊戲列車統一使用銀灰金屬車身、環境反光、深色駕駛窗與橘黑腰線。配對由伺服器管理，最多四人；Studio 以本機模式測試配對倒數、場景切換和重生。月台外有跌落保護；死亡後會在目前車站重生。站務員會在中段路程出現。各站的任務、列車廣播提示及結局文字皆為繁體中文。

## 七站劇情與任務

1. **新月站 NEW MOON**：登車並查看沒有目的地的車票。
2. **失語站 SILENT**：調查乘客簿與沉默乘客留下的線索。
3. **回聲站 ECHO**：播放真正的錄音，查明第三次循環。
4. **鏡湖站 MIRROR LAKE**：記錄異常倒影並取得實驗報告。
5. **遺忘站 FORGOTTEN**：查看監視器裡三天前的自己。
6. **終寂站 LAST MAINTENANCE**：搜尋事故紀錄，選擇相信列車長或相信證據。
7. **不存在的終點 HOME TERMINAL**：揭開玩家與事故調查的關係，選擇一般、真相或隱藏結局。隱藏結局需先讀取第六站事故紀錄。

## 專案內容

- `LastTrain.rbxlx`：直接在 Studio 開啟的遊戲 place。
- `default.project.json`：Rojo 專案設定。
- `src/ReplicatedStorage/LastTrain/Shared/GameConfig.lua`：站點故事、任務、獎勵、角色與商品設定。
- `src/ServerScriptService/LastTrain/WorldBuilder.server.lua`：程序生成的七站封閉式站區、完整隧道牆面、貼近月台的三節高鐵風格列車、主題地標和互動點。
- `src/ReplicatedStorage/LastTrain/Shared/TrainFinish.lua`、`TrainGeometry.lua`：銀色反光材質、橘黑腰線與流線駕駛車頭。
- `src/ReplicatedStorage/LastTrain/Shared/CharacterAppearance.lua`：角色制服與商店 3D 預覽共用的外觀。
- `RoundController.server.lua`：伺服器驗證任務、開關車門、移動列車與結局分支。
- `Matchmaking.server.lua`、`LobbyWorldBuilder.server.lua`：大廳四個 1–4 人走入式配對光圈箱、入口距離驗證、10 秒等候、3 秒發車動畫與保留伺服器傳送。
- `StationmasterAI.server.lua`、`PlayerSpawn.server.lua`、`RecoveryGuard.server.lua`：追逐、重生及跌落保護。
- `src/StarterPlayer/StarterPlayerScripts/LastTrainClient.client.lua`：第一人稱操作、任務 HUD、手電筒與商店介面。

若要編輯程式碼，修改 `src` 後使用 Rojo 同步或重新建置 place。未安裝 Rojo 時，也可以直接在 Studio 編輯 place 中的腳本。

## 角色與 Robux 商店

角色商店使用實際 3D 制服模型預覽，與裝備後使用同一份外觀設定；右上角 × 可關閉，開啟商店時可自由操作滑鼠。角色商店會顯示外觀和功能：列車長加快移動、號誌技師延長手電筒照射、深夜站務員縮短怪物的感知距離。遊戲幣角色由伺服器扣款與解鎖；Robux 角色以 Game Pass 查驗，Robux 換遊戲幣以 Developer Product 收據核發。請先在 Creator Dashboard 建立商品，將商品 ID 填入 `GameConfig.lua`；目前範例 ID 為 0，因此需完成商品設定後才會啟用實際 Robux 購買。不要把售價填到 ID 欄位。

Studio 測試期間使用暫存玩家資料。要測試 DataStore 儲存，先發布測試體驗，再於 Game Settings > Security 開啟 Studio Access to API Services。付費商品應先在測試體驗完成設定與驗證。

## 美術與裝置

地圖使用 Future 燈光、弧形站台雨棚、圓柱支撐、黃色止滑導盲帶與青藍燈帶。月台補上細石材分縫、站色方向線與立體月台號碼柱；大廳加入石材地坪鑲線、電子發車資訊、七站路線圖與列車展示底盤／轉向架。列車參考台灣高鐵 700T 的白色長車身、流線車鼻與大片深色駕駛窗，也參考 Roblox 列車模擬作品把車輪、轉向架、車門、車頂設備、車廂資訊燈和內裝做出可近看的層次；成品採用銀灰金屬車身與橘黑腰線，不複製其他遊戲的模型或標誌。三節車廂以可通行的連接處銜接，內裝補上圓潤座椅、扶手、置物架、走道地毯與暖白燈。角色商店四套制服加上統一比例的帽飾、徽章和袖口細節；切換角色時清除會蓋住制服的玩家衣物和頭飾，保留臉孔與膚色。停靠時只開啟月台側車門，踏板補齊登車處。新增隧道端牆、車站牆板、嵌燈與維修門。第二車廂的失蹤廣播與第三車廂的舊車票，會揭露列車循環與玩家身分。流線車頭以連續貼合的三角曲面組成，駕駛窗直接沿車鼻曲面配置。車廂使用完整長度的頂板、圓弧肩線與中空摺棚，兩處接縫保留通暢走道。隧道牆面、地基與頂板分為不超過 512 studs 的段落，避免超長零件遭截短。場景由原生 Roblox 零件和內建球面網格組成，方便直接在 Studio 調整或替換成自製／授權 MeshPart、貼圖與音效。環境音留有可填入自有音效 ID 的位置。

銀色版配色參考台灣高鐵的[官方橘黑線條設計說明](https://www.thsrc.com.tw/ArticleContent/e1e25e6a-4139-44d4-ac30-3f9724f08310)。車身依本遊戲需求改為銀灰金屬，反射效果隨 Roblox 畫質與場景光源而變化。

列車外型研究參考：[THSR 700T 車頭照片](https://commons.wikimedia.org/wiki/File:THSR_700T_Front_view.jpg) 和 [Roblox TOHOKU SuperExpress 列車模擬](https://www.roblox.com/games/7035697453/TOHOKU-SuperExpress-Bullet-Train-Sim)。這些連結只作比例、車窗和車頂細節的參考，遊戲未使用它們的模型、貼圖或音效。

請在目標裝置上調整 Studio 的 Editor Quality Level，並檢查低階手機上的可見度和效能。所有音效與外部素材請使用自行製作或取得授權的內容。
