# 末班車：每站不同玩法

所有月台任務都免費。每個任務台上方都有金色名稱標記，靠近後按 E 或畫面互動鍵開啟。完成任務後返回列車；列車會等全員上車、倒數並關門。關門途中有人離開仍會重新開門。

| 站別 | 玩法 | 操作重點 |
|---|---|---|
| 1 新月站 | 領票與個人刷卡 | 每人領取白橘車票，再感應閘門，上車後開始旅程。 |
| 2 失語站 | 搜尋與身分比對 | 在月台找齊三張金色行李牌，回乘客紀錄台，比對誰的離站欄空白。 |
| 3 回聲站 | 燈號順序記憶 | 記住四次亮燈，依序按青、黃、紅燈；可隨時重播。錯誤只重設這段燈號輸入。 |
| 4 鏡湖站 | 實景對焦拍攝 | 對準鏡面旁藍色人影，穩定兩秒，按 C 或畫面快門拍下異常倒影。 |
| 5 遺忘站 | 監視器倒帶 | 切換 2 號鏡頭、找出三天前 23:47 的影格，再截存多出的乘客。 |
| 6 終寂站 | 配電旋鈕與劇情分支 | 依接線圖轉動三個旋鈕。通電後選擇相信站務員，或讀取事故紀錄。 |
| 7 不存在的終點 | 核心時機操作與結局 | 游標進入綠色區域時按穩定，完成三個節點後選結局。隱藏結局仍需第六站事故紀錄。 |

## 第五站詳細教學

1. 下車後沿月台尋找「監視器調閱台」的金色標記；不是只站在裝飾螢幕前。
2. 靠近任務台，按 E／畫面互動鍵。
3. 按「2 號鏡頭」。
4. 使用「前進 ▶」或「◀ 倒帶」調整時間至 **23:47**。畫面一開始是 23:38，所以前進三格即可。
5. 畫面會出現第四名紅色乘客，並提示「異常：多出一名面向鏡頭的乘客」。稍微停留，看清影格。
6. 按「截存這一格證據」。任務完成後回到列車，等待隊友上車。

切錯鏡頭、停在其他時間或截存太快，畫面會提示原因，可以直接重試。

## 合作與操作

- 行李牌、燈號進度、配電旋鈕及核心節點為本局全隊共用。一人完成後，所有人都可繼續旅程。
- 第二、三站任務台周圍的藍色地面區域可安心閱讀與操作；離開安全區搜尋時仍可能被追逐。任務完成後停止追逐，讓隊伍返車。
- 關閉一般任務視窗：右上角 ×、Q 或 Esc。攝影模式使用 Q／畫面離開按鈕；C 拍攝。
- 第七站亦可按空白鍵穩定節點；時機失誤不會扣除已完成節點。
- 死亡或離開任務台會關閉視窗；本局的團隊已完成進度會保留。重新靠近任務台可以繼續。
- 第六站的選擇及第七站的結局，由伺服器確認。每站獎勵只發放一次。
- 月台改動不移動列車本體，不改動既有商品 ID、價格或銀河限量。

## 版本與更新

這份教學對應「七站不同玩法」版本。已在進行中的舊伺服器不會自動更換腳本，需要重新加入更新後的私人遊戲，或在 Studio 開啟新版檔案重新 Test。

## 第七站：三種結局動畫

完成三次核心穩定後，選擇結局即播放約 16 秒的專屬動畫：

| 結局 | 動畫內容 |
|---|---|
| 離開 · 晨光之後 | 站務員揮手、出口門滑開，鏡頭走向晨光與城市；最後揭露廣播是自己的聲音。 |
| 真相 · 循環終止 | 七站燈光依序熄滅、核心停止運作，站務員的陰影消失並道謝。 |
| 隱藏 · 第八站 | 七個站名消失，封門滑開並露出星光通道，看板轉為 STATION 08。需先閱讀第六站事故紀錄。 |

- 播放兩秒後可按「略過」、空白鍵或 Esc。
- 結束後保留完整劇情文字，可重播或返回遊戲畫面；支援觸控按鈕。
- 動畫僅使用獨立場景與本機鏡頭。真實列車與角色不會被動畫移動。
- 動畫結束、略過、離開或重生時，會清理動畫場景並還原鏡頭、環境光與操作。
