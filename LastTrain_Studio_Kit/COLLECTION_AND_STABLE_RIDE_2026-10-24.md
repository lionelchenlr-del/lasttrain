# 末班車：穩定行車與精品版本

## 遊玩方式

開啟 LastTrain.rbxlx，在 Roblox Studio 按 Test。從大廳選擇 1–4 人隊伍；Studio 會啟動本機遊戲，正式版本使用獨立遊戲房間。

第一站依序領取免費白橘車票、感應閘門、登上列車。每位乘客都要驗票；驗票狀態會保留到同一局結束。第二站起完成月台任務後，列車會等全員上車，再倒數、關門。關門途中有人離開會重新開門。

- WASD：走動；滑鼠：觀看；空白鍵：跳躍。
- E：依畫面提示互動、坐下、上下車。
- F：開關手電筒。
- M：車票幣服裝；P：精品商店。
- 商店可預覽、旋轉角色或商品；皇家／銀河頁面可開啟「全尺寸展示」，切換外觀與內裝，按返回離開展示。

## 行車設計

車體、地板、車廂連通道、座椅與乘客不進行整列搬移。行駛效果由窗外隧道、軌道細節與月台移動呈現；七站的場景各自使用相同的停靠位置。到站後才開放該站月台碰撞與互動。

這移除了原本逐幀搬動列車、搬動角色與玩家走路更新互相干擾的來源。經過座椅也不會被自動吸去坐下，須主動互動。途中重生會回到列車內；停站重生則回到目前月台。

車身維持白橘配色、平整腰線、流線車頭與整合燈組。透明窗使用不折射材質；飾條改用連續表面。手電筒亮度調低，減少近距離白色內裝過曝。

```text
流線車頭／駕駛室
      │
第一車：一般乘客區、失蹤廣播
      ║ 密封連通道
第二車：一般座位＋商務座位
      ║ 密封連通道
第三車：皇家座位包廂、舊車票
      │
後端駕駛室／流線車尾
```

一般走道對所有玩家開放。購買座位權益不會略過車票或劇情任務。皇家座位不要求另購商務通行證。

## 正式收費：已設定八項商品，遊戲仍為私人

已於 Universe 10772691974 建立七項通行證與一項銀河開發者商品，填入正式 ID，設定售價並儲存到私人遊戲。詳細 ID 與發佈待辦請見 `release/發佈準備.md`。下列為維護說明；目前商品已建立，不需重建。Studio 保持預覽，正式伺服器才可開啟付款。

1. 在 Roblox Creator Hub 選擇此遊戲，開啟「營利／Monetization → 通行證／Passes」。
2. 為前七個項目建立通行證。銀河高鐵另在「Developer Products／開發者商品」建立 999 R$ 商品；不要開啟站外銷售，限從遊戲內保留編號後購買。
3. 複製各自 ID。Studio 中開啟 `ReplicatedStorage → LastTrain → Shared → PremiumCatalog`，將前七項的 `PassId=0` 換成通行證 ID，銀河商品則填入 `ProductId=0`。使用原始碼工具時，修改 `src/ReplicatedStorage/LastTrain/Shared/PremiumCatalog.lua` 後重新建置。
4. 另須依 `release/發佈準備.md` 填寫目標 Universe ID 與 Place ID，並使用 `tools/configure_release.py` 啟用正式付款。未完成時 `ReleaseSettings.BillingEnabled` 保持 false。發布更新後，以正式伺服器確認顯示價格、購買取消、成功解鎖與重新登入恢復。

`BasePrice` 是預定基準價格，不能代替 Roblox 後台售價。正式 ID 設好後，商店會讀取玩家端 Roblox 回傳價格，以反映地區價格或折扣；最終收費以 Roblox 購買視窗為準。

伺服器確認通行證擁有權後才解鎖，進入遊戲時重新查驗。座位與候車區另有伺服器檢查。資料更新保留原有車票幣與服裝，並儲存新權益、列車外觀與手電筒選擇。

## 皇家與銀河參考圖設計

依使用者提供的皇家／星空高鐵圖，皇家版採香檳白金車身、金色腰線、象牙色座位、木飾餐桌、休息床與茶飲吧。銀河版採深藍紫星雲車頭、發光腰線、平面星球徽記、星空頂棚與冷色座椅。

徽記與星光使用貼合表面的介面圖層或既有外殼上色；不在車頭添加皇冠、球體、外凸燈具或懸浮裝飾。星雲效果只調整圖層顏色，不移動車身、不使用鏡頭震動。

皇家擁有者可在遊戲中的皇家商品頁邀請同車朋友，本局可共用皇家座位及茶飲吧。受邀資格不會寫成永久購買權益。茶飲吧提供背包茶飲，裝備後點擊品嚐。

## 銀河高鐵限量 500 台

這是全遊戲共用的 500 個永久編號，每位帳號最多一台。不是每個伺服器各 500 台，也不是只在標題顯示限量。

- 遊戲先在共用 DataStore 以 UpdateAsync 保留編號，確認成功才開啟付款。
- Roblox 收據確認後才發放編號及造型；相同收據重試與重新登入不會取得第二台。
- 付款前斷線或關閉付款窗，編號保留給原帳號，可稍後繼續，避免延遲收據碰上被重新出售的編號。因此「已領取」與「保留中」分開計算，保留名額不會被說成已售出，也不會自動逾時釋出。
- 500 個編號都被領取或保留後，停止接受新編號。已保留者仍能完成原本的購買。
- 庫存服務無法讀寫時，停止開啟付款；不使用假庫存補位。
- 正式庫存位於 `LastTrain_LimitedEd_v1 / Galaxy500_v1`。未發布 Studio 使用本機暫存庫存作測試，不佔正式名額。

銀河商品必須使用上述遊戲內購買流程，並保持開發者商品的站外銷售關閉，才能讓每次付款先取得保留名額。正式跨伺服器庫存及 Robux 付款仍須在發布並填好 ProductId 後實測。
